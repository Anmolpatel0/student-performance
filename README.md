# EduPredict — Student Progress Classifier

A small end-to-end machine-learning portfolio project. Train a Decision Tree classifier, save the fitted pipeline with Joblib, and load it inside an interactive Streamlit application.

## What it demonstrates

- Supervised binary classification
- Train/test split and model evaluation
- Model persistence with `joblib`
- Interactive inputs and real-time predictions in Streamlit
- A simple model card and dataset explorer

## Project files

| File | Purpose |
|---|---|
| `train.py` | Creates the teaching dataset, trains the model and saves artifacts |
| `app.py` | Loads the saved model and runs the interactive web app |
| `requirements.txt` | Python dependencies |
| `student_model.joblib` | Generated model artifact |
| `model_metrics.json` | Generated evaluation metrics |
| `student_data.csv` | Generated synthetic dataset |

## Run locally (macOS / Linux)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 train.py
python3 -m streamlit run app.py
```

Open the local URL printed in the terminal (usually `http://localhost:8501`).

**Important:** Run `train.py` before starting the app. It creates `student_model.joblib`, `model_metrics.json`, and `student_data.csv`.

## Deploy on Streamlit Community Cloud

1. Run `python3 train.py` locally once.
2. Push `app.py`, `train.py`, `requirements.txt`, `student_model.joblib`, `model_metrics.json`, and `student_data.csv` to a GitHub repository.
3. Open https://share.streamlit.io/ and sign in with GitHub.
4. Choose the repository, branch, and `app.py` as the main file.
5. Deploy.

Do not upload `.venv/`, secrets, or personal data. The model artifact must be committed because the hosted app loads it directly.

## Data and responsible use

The included dataset is synthetic and generated by a transparent rule with random variation. It is intended only to demonstrate a machine-learning workflow. The model has not been validated on real student records and must not be used to make decisions about actual students.
